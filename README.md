# Movie Library (Личная кинотека)

## 👤 Автор

**Имя и фамилия:** Рахматуллин Даниель

## 📝 Описание

**Movie Library** - это удобное десктопное приложение для создания и управления личной коллекцией фильмов. Приложение позволяет вести базу данных просмотренных фильмов, оценивать их и фильтровать по различным критериям.

### Основные возможности:

✅ **Управление фильмами**
- Добавление новых фильмов с указанием названия, жанра, года выпуска и рейтинга
- Редактирование существующих записей
- Удаление фильмов с подтверждением

✅ **Валидация данных**
- Проверка года выпуска (должен быть числом от 1888 до текущего года + 5)
- Проверка рейтинга (число от 0 до 10)
- Информативные сообщения об ошибках

✅ **Фильтрация и поиск**
- Фильтрация по жанру
- Фильтрация по году выпуска
- Сброс всех фильтров одним кликом

✅ **Хранение данных**
- Автоматическое сохранение в формате JSON
- Ручное сохранение и загрузка данных
- Персистентность данных между сеансами

✅ **Статистика и аналитика**
- Общее количество фильмов в коллекции
- Средний рейтинг всех фильмов
- Диапазон годов выпуска
- Количество уникальных жанров
- Лучший фильм по рейтингу

## 🚀 Установка и запуск

### Системные требования

- Python 3.7 или выше
- Tkinter (входит в стандартную библиотеку Python)

## Использование
### Добавление фильма
1. Заполните поля в верхней части окна:
 * Название: Полное название фильма
 * Жанр: Выберите из выпадающего списка
 * Год выпуска: Укажите год (число от 1888 до текущего года + 5)
 * Рейтинг: Оценка от 0 до 10 (можно использовать дробные числа)
2. Нажмите кнопку "🎬 Добавить фильм"
3. При успешном добавлении появится подтверждение с визуальным отображением рейтинга звездочками

### Фильтрация фильмов
 * По жанру: Выберите нужный жанр в выпадающем списке "Фильтр по жанру"
 * По году: Введите год в поле "Фильтр по году" (например: 1994)
 * Сбросить фильтры: Нажмите кнопку "🗑️ Сбросить фильтры"

### Редактирование и удаление
1. Выберите запись в таблице, кликнув по ней
2. Для редактирования нажмите "✏️ Редактировать"
3. Для удаления нажмите "🗑️ Удалить выбранный"

### Сохранение и загрузка
* Данные автоматически сохраняются при каждом изменении
* Используйте кнопки "💾 Сохранить в JSON" и "📂 Загрузить из JSON" для ручного управления

## Примеры использования и тесты
### Тест 1: Добавление валидного фильма
#### Действие: Добавить фильм с корректными данными
 * Название: "Побег из Шоушенка"
 * Жанр: Драма
 * Год: 1994
 * Рейтинг: 9.3

#### Ожидаемый результат:
 * Появляется сообщение об успешном добавлении с 9 звездочками
 * Фильм отображается в таблице
 * Обновляется статистика

### Тест 2: Ошибка при неверном годе
#### Действие: Добавить фильм с неправильным годом
 * Название: "Начало"
 * Жанр: Фантастика
 * Год: 20ab
 * Рейтинг: 8.8

### Ожидаемый результат:
 * Появляется сообщение об ошибке "Год должен быть числом"
 * Фильм не добавляется

### Тест 3: Ошибка при рейтинге вне диапазона
#### Действие: Добавить фильм с рейтингом 11
 * Название: "Криминальное чтиво"
 * Жанр: Криминал
 * Год: 1994
 * Рейтинг: 11

#### Ожидаемый результат:
 * Сообщение об ошибке "Рейтинг должен быть от 0 до 10"
 * Фильм не добавляется

#### Действие:
1. Добавить несколько фильмов разных жанров:
 * "Матрица" (Фантастика, 1999, 8.7)

#### Действие:
1. Добавить фильмы разных годов:
 * 1994: "Форрест Гамп", "Криминальное чтиво"

#### Ожидаемый результат:

#### Ожидаемый результат:

3. Проверить ID оставшихся фильмов

 * "Крестный отец" (1972)
